# Authentication Module

This authentication module is built on rocket web framework, using a PostgreSQL database with diesql.

It is not hosted yet.

## Functionality

* Done
  * signup
  * login
  * reset password
  * logout

* Todo
  * forget password

All errors lead to `Status::BadRequest` and a simple string for now.

## Install dependency

``` shell
rustup default nightly && rustup update
sudo apt-get install libpq-dev
cargo install diesel_cli --no-default-features --features postgres
```

## How to Use

1. `cp .env.example .env` and fill in the values (`.env` is git-ignored; never commit it).
2. `set -a && . ./.env && set +a` to export the variables to your shell.
3. `diesel migration run`
4. `cargo run`

Secrets are read from environment variables, not from `Rocket.toml`:

* `ROCKET_DATABASES`: database connection for Rocket.
* `ROCKET_SECRET_KEY`: required in release builds; generate one with `openssl rand -base64 32`.
* `DATABASE_URL`: used by the diesel CLI.

## Run with docker

Create `.env` from `.env.example` first; docker compose reads `POSTGRES_PASSWORD` and `ROCKET_SECRET_KEY` from it.

``` shell
docker-compose up -d
docker-compose down
```

``` shell
docker run -it --rm  postgres psql -h Your IP -U rudrist_admin -d rudristdb
```

The following lists the available sites for now:

* "/index"
* "/signup"
* "/login"
* "/user_center"
* "/logout"
